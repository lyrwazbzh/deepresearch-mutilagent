# DeepResearch 工具路由模型操作手册

以下命令均在仓库的 `training/` 目录执行。API 密钥只通过 `LLM_KEYS` 环境变量注入。

## 1. 准备种子与合成数据

种子文件为 JSON 或 JSONL，每条包含：`id`、`question`、`industry`、
`question_type`、`difficulty`，可选 `expected_tools`。

```bash
python scripts/expand_seed_questions.py \
  --input data/reviewed_seeds.jsonl \
  --output data/expanded_seeds.jsonl \
  --target 6500

python scripts/synthesize_routing_trajectories.py \
  --seed-file data/expanded_seeds.jsonl \
  --output data/raw/teacher-trajectories.jsonl \
  --target-valid 6000 --workers 8
```

扩展目标高于最终目标，是为了给质量过滤与去重留出余量。脚本按 `seed_id` 断点续跑。

## 2. 构建数据集

```bash
python scripts/build_dataset.py \
  --input data/raw/teacher-trajectories.jsonl \
  --output-dir data/routing-v1 \
  --target-valid 5000 --min-quality 0.75
```

成功后会生成 `train.jsonl`、`dev.jsonl`、`test.jsonl` 和 `manifest.json`。
同一 `seed_id` 的变体不会跨数据集，避免评测泄漏。

## 3. 4-bit QLoRA

```bash
python scripts/02_train.py \
  --train-data data/routing-v1/train.jsonl \
  --eval-data data/routing-v1/dev.jsonl \
  --model-path Qwen/Qwen2.5-7B-Instruct \
  --output-dir outputs
```

默认使用 NF4、double quant、LoRA r=16/alpha=32；通过
`--resume-from-checkpoint outputs/.../checkpoint-N` 恢复中断训练。

## 4. 独立测试集评测与发布门禁

先评估基座并保存结果，再评估 Adapter：

```bash
python scripts/evaluate_tool_router.py \
  --model Qwen/Qwen2.5-7B-Instruct \
  --eval-data data/routing-v1/test.jsonl \
  --output reports/baseline.json \
  --report-only

python scripts/evaluate_tool_router.py \
  --model Qwen/Qwen2.5-7B-Instruct \
  --adapter outputs/<run>/adapter \
  --eval-data data/routing-v1/test.jsonl \
  --baseline-result reports/baseline.json \
  --output reports/candidate.json \
  --min-tool-accuracy 0.90 --min-schema-validity 0.98
```

```bash
python scripts/package_release.py \
  --training-run outputs/<run> \
  --evaluation reports/candidate.json \
  --release-dir releases/<version>
```

门禁不通过时脚本以非零状态退出，不生成发布目录。

## 5. 推理服务与主项目灰度

```bash
docker build -f Dockerfile.serve -t deepresearch-tool-router:local .
docker run --gpus all --env-file deploy/tool-router.env \
  -p 8080:8080 deepresearch-tool-router:local
```

在仓库的 `backend/.env` 中配置：

```dotenv
TOOL_ROUTER_ENABLED=1
TOOL_ROUTER_BASE_URL=http://tool-router:8080
TOOL_ROUTER_API_TOKEN=<same-internal-token>
TOOL_ROUTER_GRAY_PERCENT=10
TOOL_ROUTER_MIN_CONFIDENCE=0.65
```

灰度按 `session_id` 稳定哈希，Adapter 超时、低置信度、非法工具或参数不符合 Schema
时自动回退确定性规则路由。
